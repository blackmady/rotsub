# Kinetic Typography Studio · 旋转堆叠动态字幕生成器

一款**零配置、单文件 HTML** 的短视频爆款「旋转堆叠动态字幕（Kinetic Typography）」制作与极速导出工具。无需安装 Node.js 或任何本地服务，双击即可在浏览器中运行，支持 `.srt` 字幕智能排版与 GPU 硬件加速导出标准 `.mp4` / 透明通道 `.webm`。

## 核心特性

### 1. 虚拟摄像机与 90° 旋转堆叠引擎
* **无限 2D 世界坐标系**：所有字幕在世界坐标中预计算排版位置，虚拟摄像机通过平移、缩放与平滑 90° 旋转追踪当前最新字幕。
* **历史层次保留**：触发旋转后，旧字幕自动转为竖排停靠在画面边缘，并按层级递减透明度，避免画面单调。
* **自适应视觉冲击**：根据每行字数自动缩放字号以撑满版心（字越少字号越大），并内置安全宽度硬限，**确保超长词句绝不超出屏幕**。

### 2. 智能 SRT 排版与原子分词
* **开箱即用**：支持点击导入或直接将 `.srt` 字幕文件拖入编辑区，自动保留精准时间轴。
* **原子分词防折行**：英文单词（如 `WebCodecs`）与数字单位（如 `300%`、`60fps`）锁定为不可分割的整体，绝不会跨行劈开。
* **节奏感知旋转**：自动分析字幕停顿间隙、句末标点与堆叠行数，在合适节点插入交替的 `[左转]` / `[右转]` 转场。
* **重点词精准突出**：自动识别数据/百分比、引号概念、英文专有名词与高频核心词并添加 `*...*`；混合行内的重点词将以 **1.22 倍更大字号 + 高亮色 + 二次弹性跳动** 渲染。

### 3. 偶发多变物理动效
内置 6 种确定性随机动效（拖动进度条与导出结果 100% 一致），可通过滑块调节丰富度与弹性系数：
* **重击砸落（Slam）**：放大砸下并触发轻微镜头震动。
* **高速甩入（Whip Left / Right）**：侧向高速切入并带倾斜惯性回弹。
* **弹簧坠落（Spring Drop）**：真实阻尼弹簧物理 + 落地挤压拉伸（Squash & Stretch）。
* **橡皮筋拉伸（Elastic Stretch）** 与 **经典弹性弹出（EaseOutBack）**。

### 4. 极速轻量视频导出
* **离屏文字缓存（Sprite Cache）**：预渲染文字与投影，彻底消除实时 `shadowBlur` 性能瓶颈。
* **静止帧合并（VFR）+ GPU 硬编**：优先调用 `WebCodecs API` + `mp4-muxer`，动画期间满帧率渲染，静止停留期自动合并编码帧，搭配 VBR 动态码率，**导出速度提升 3~5 倍，体积缩小 75% 以上**。
* **多背景与透明通道**：支持纯黑 `#000000`、绿幕 `#00FF00`（导出 `.mp4`）以及透明 Alpha 背景（自动导出 VP9 `.webm`）。
* **本地配音同步**：支持加载 MP3 / WAV / M4A 配音文件，预览与导出自动混流音轨。

## 快速开始

1. 下载或保存 `kinetic-typography-v5.html` 到本地。
2. 使用 **Chrome** 或 **Edge** 浏览器双击打开即可体验内置示例（首次导出 MP4 需联网加载 CDN 上的 `mp4-muxer`，离线会自动降级为 `MediaRecorder`）。
3. 拖入 `.srt` 文件（或手动编写文案）→ 调整画幅/颜色/帧率 → 点击**「极速渲染并导出 MP4」**。

## 脚本语法说明

每行代表一句字幕，支持以下标记自由组合：

| 语法 | 作用 | 示例 |
| :--- | :--- | :--- |
| `*文字*` | 标红高亮，混合行内自动放大 1.22 倍 | `效率直接提升 *300%*` |
| `[左转]` / `[右转]` | 触发摄像机逆时针 / 顺时针 90° 旋转 | `[右转] 拖入 *SRT* 文件` |
| `[旋转]` | 自动左右交替触发 90° 旋转 | `[旋转] 下一组字幕` |
| `\| 秒数` | 指定当前行持续时长（不填则按字数自动计算） | `超轻量 *MP4* 视频 \| 1.5` |
| `[起 -> 止]` | 精准时间轴模式（导入 SRT 时自动生成） | `[00:01.20 -> 00:02.50] 精准对齐` |

## 剪辑软件叠加建议

* **剪映 / Premiere Pro / 达芬奇（推荐工作流）**：
  选择**纯黑背景**导出 `.mp4`，拖入剪辑软件主画面上方轨道，将混合模式设为 **「滤色 (Screen)」** 或 **「变亮 (Lighten)」** 即可一键无损去黑底。
* **绿幕抠像**：选择**绿幕背景**导出 `.mp4`，在剪辑软件中使用色度抠图。
* **原生透明通道**：选择**透明 Alpha** 背景，工具将自动导出带 Alpha 通道的 `.webm (VP9)` 文件。

## 技术栈

* **渲染引擎**：原生 HTML5 2D Canvas + 离屏 Sprite 缓存
* **视频编码**：WebCodecs API (`VideoEncoder` / `AudioEncoder`) + [mp4-muxer](https://github.com/Vanilagy/mp4-muxer)（降级方案：`MediaRecorder API`）
* **音频处理**：Web Audio API
